The GitHub repository comprises multiple branches, each containing a distinct web development project, such as MedicalPlatform, MedicalStore, and FoodDelivery.

• Medicine Selling Website — PHP, CSS, JavaScript, MySQL, HTML
Developed a dynamic and user-friendly e-commerce platform for online medicine sales, incorporating secure database management and efficient user interaction features.

• Medical Platform (Patients, Doctors & Shops) — MERN Stack
Engineered a scalable healthcare management system that seamlessly integrates multi-role access for patients, doctors, and medical shops, with robust authentication and data handling mechanisms.

• Food Delivery Shop — MERN Stack
Designed and implemented a responsive and intuitive online food delivery platform featuring real-time order tracking, optimized performance, and a smooth user experience across all devices.
